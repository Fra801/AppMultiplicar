# Multiplicar

Práctica de cálculo mental con números de dos cifras. Escribís el resultado, tocás **Comprobar** y la app te dice si está bien (verde) o mal (rojo).

## Tipos de ejercicio

- **Multiplicadores**: un número de dos cifras al azar por 5, 25, 11, 99, 15 o 21, en cualquier orden. Se puede fijar un solo multiplicador.
- **Decenas iguales**: dos números con la misma decena y unidades que suman 10 (por ejemplo 34 × 36).
- **Mixto**: alterna entre los dos.

## Usarla como app

La app es una página estática. Con GitHub Pages queda en `https://<tu-usuario>.github.io/AppMultiplicar/`.
Desde el celular, abrí esa dirección y elegí **Agregar a pantalla de inicio**.

## Guardar el progreso con tu cuenta

En **Progreso → Cuenta y copia de seguridad** pegás un token de GitHub con el permiso `gist`. La app crea un gist privado llamado `multiplicar.json` y lo mantiene sincronizado entre dispositivos. El token se guarda solo en el navegador. También podés descargar y cargar una copia en un archivo.

Sin iniciar sesión, el progreso queda solo en el navegador (`localStorage`).
